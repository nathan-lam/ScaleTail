## Linting

[rumdl](https://open-vsx.org/vscode/item?itemName=rvben.rumdl) is used for linting which can be installed as an extension and pip ```pip install rumdl==0.3.0```

To execute a linting check execute ```rumdl check --config .markdownlint.yml .```
